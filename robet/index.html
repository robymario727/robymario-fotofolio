About Me

Halo! Saya Roby Mario, siswa SMK jurusan Pengembangan Perangkat Lunak dan Gim (PPLG). Saya memiliki ketertarikan dalam dunia teknologi, pemrograman, dan pengembangan website.

Saya sedang mengembangkan kemampuan dalam HTML, CSS, JavaScript, dan Java. Saya senang mempelajari hal baru, mencoba berbagai teknologi, serta membuat proyek sebagai sarana belajar.
